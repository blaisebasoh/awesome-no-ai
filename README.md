# Awesome no-AI
A curated list of AI free softwares and tools.

This is not a list of softwares not using AI in their development since it will be a very difficult and almost impossible list to find, If stated by the developers, it'll be indicated here.
This is a list of softwares with zero [generative AI](https://en.wikipedia.org/wiki/Generative_AI) features (because they're now overly unnecessary forced into every piece of software).

## Projects

   - [Gimp](https://www.gimp.org/) - A free and open source image editing software. Gimp has features for illustration, graphic design etc.
